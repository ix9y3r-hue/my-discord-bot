# بوت الموسيقى لديسكورد

نسخة جاهزة للنشر على GitHub ثم Render باستخدام Docker. يتضمن المشروع تثبيت FFmpeg تلقائيًا، لذلك لا تحتاج إلى تثبيته يدويًا على Render.

## قبل النشر

1. أنشئ بوتًا من [Discord Developer Portal](https://discord.com/developers/applications).
2. من **Bot → Privileged Gateway Intents** فعّل **Message Content Intent**.
3. أضف البوت إلى سيرفرك بصلاحيات قراءة القنوات، إرسال الرسائل، الاتصال بالروم الصوتي والتحدث.
4. ارفع كل ملفات هذا المجلد إلى مستودع GitHub جديد. لا ترفع توكن البوت أبدًا.

## النشر على Render

1. افتح [Render](https://render.com) واختر **New → Blueprint**.
2. اربط مستودع GitHub الذي رفعت إليه الملفات.
3. وافق على إنشاء الخدمة من `render.yaml`.
4. في إعدادات الخدمة، أضف قيمة `DISCORD_TOKEN` من Discord Developer Portal ضمن **Environment**.
5. ابدأ النشر وافتح **Logs** للتأكد من ظهور تسجيل الدخول للبوت.

## أوامر البوت

- `!ادخل` — يدخل الروم الصوتي الذي أنت فيه.
- `ش اسم الأغنية` — يبحث عن أغنية ويضيفها للتشغيل.
- `وقف` — إيقاف مؤقت.
- `ك` أو `كمل` — استكمال التشغيل.
- `س` أو `سكب` — تخطي الأغنية.
- `كرر` — تشغيل الأغنية الحالية بشكل متكرر.
- `طابور` — عرض قائمة الانتظار.
- `!اخرج` — الخروج من الروم الصوتي.

## ملاحظات مهمة

- يجب أن تكون صلاحية **Message Content Intent** مفعّلة في بوابة Discord؛ تفعيلها في الكود وحده لا يكفي.
- خطة Render المجانية قد توقف الخدمة أو تدخلها في وضع السكون، لذلك لا تضمن تشغيل البوت الصوتي على مدار الساعة. للاستمرارية، استخدم استضافة لا تنام وتسمح باتصالات Discord الصوتية.
- ملف حالة الروم في `/tmp` مؤقت وقد يُفقد بعد إعادة التشغيل. لا يحفظ هذا الإصدار قائمة الأغاني أو حالة التشغيل كاملة.
- روابط Spotify لا تعمل مباشرة؛ اكتب اسم الأغنية بدلًا منها.
- إذا تعطل البحث أو التشغيل، راجع **Logs**؛ مواقع بث الموسيقى قد تغيّر آلياتها، وقد تحتاج مكتبة `yt-dlp` إلى تحديث.
